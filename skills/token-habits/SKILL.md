# 토큰 아끼는 습관

Claude Code 공식 문서에서 확인된 방법만 안내합니다. 줄어드는 양은 사람마다 다르므로 "몇 % 절약" 같은 수치는 말하지 않고, 효과는 `/usage`로 직접 확인하게 합니다. 사용자는 비개발자일 수 있으니 용어는 한 줄로 풀어 설명합니다.

## 1. 서브에이전트에 더 싼 모델 쓰기

서브에이전트(Claude가 일을 나눠 맡기는 보조 에이전트)가 어떤 모델로 돌지는 아래 순서로 정해지고, 먼저 나온 것이 이깁니다.

1. Claude가 서브에이전트를 시작하면서 넘기는 `model` 값
2. 서브에이전트 정의 파일의 `model:` 줄 (`haiku`, `sonnet`, `opus` 같은 별칭)
3. 환경변수 `CLAUDE_CODE_SUBAGENT_MODEL`
4. 메인 대화의 모델

- **특정 서브에이전트만 싸게**: 그 에이전트 정의 파일의 `model:`에 `haiku`를 적습니다.
- **모든 서브에이전트를 한 모델로**: Claude Code 2.1.257 이상에서 설정 파일의 `env`에 두 값을 함께 둡니다. 이렇게 하면 에이전트 정의의 `model:`은 무시되고 Claude도 모델을 고를 수 없으므로, 어려운 일에도 같은 모델이 쓰인다는 점을 사용자에게 알리고 어느 모델로 할지 먼저 확인합니다.

```json
{
  "env": {
    "CLAUDE_CODE_SUBAGENT_MODEL": "haiku",
    "CLAUDE_CODE_SUBAGENT_MODEL_FORCE": "1"
  }
}
```

- `CLAUDE_CODE_SUBAGENT_MODEL`만 두면 기본 제공 Explore와 Plan 서브에이전트의 모델은 바뀌지 않습니다. 전체에 적용하려면 `_FORCE`도 필요합니다.
- 실제로 어떤 모델로 도는지는 서브에이전트가 실행 중일 때 `/tasks`를 입력하면 줄마다 나옵니다 (2.1.242 이상).

## 2. 어디서 쓰이는지 보기

- `/usage`: 구독 요금제(Pro, Max, Ultra, Team, Enterprise)에서는 최근 사용량이 스킬, 서브에이전트, 플러그인, MCP 서버별 비율로 나옵니다. 이 컴퓨터의 기록으로 계산한 근삿값이고, 다른 기기나 claude.ai 사용은 들어 있지 않습니다. 줄일 만한 항목의 추천도 함께 나옵니다.
- `/context`: 지금 문맥(Claude가 한 번에 기억하는 대화 공간)을 무엇이 차지하고 있는지 보여 줍니다.

둘 다 사용자가 직접 입력하는 명령이므로 입력해 보라고 안내하고, 결과를 알려 주면 함께 해석합니다.

## 3. 자동 compact 시점 고르기

문맥이 가득 차기 전에 대화를 요약해 줄이는 것을 compact라고 하고, 그 시점은 직접 정할 수 있습니다.

- `/autocompact 500k`처럼 크기를 주면 현재 모델에 저장되어 이후 세션에도 적용됩니다.
- `/autocompact auto`는 모델에 맞게 정해진 기본값으로 되돌립니다.
- 모든 모델에 한꺼번에 적용하려면 설정 파일(`~/.claude/settings.json`)에 `"autoCompactWindow": 200000` 같은 줄을 넣습니다.

## 4. 터미널 명령 출력 줄이기 (rtk)

이 플러그인의 훅은 터미널 명령을 rtk라는 프로그램을 거치도록 바꿔 출력을 짧게 만듭니다. rtk가 설치되어 있어야 동작하고, 없으면 아무 일도 하지 않습니다.

- 설치 확인: `rtk --version`
- Homebrew가 있다면: `brew install rtk`
- Windows: `winget install rtk-ai.rtk`
- `cargo install rtk`는 쓰지 않습니다. rtk 공식 안내가 경고하듯, crates.io의 `rtk`는 이름만 같은 다른 프로젝트입니다.
